# python-turn-based-card-battle-game
Turn based python card battle game with random card draws, action points, scaling damage cards, healing, blocking, etc.

## Features
- Turn based combat
- Random card draws
- Action Points (AP), a points system to limit the amount of cards that can be played
- Each card has unique attributes
- Upgradeable Hew card that increases damage every time its played or when the turn ends
- Fighting Spirit card allows the highest AP card to be played for the cost of 1 AP
- Random enemy dmg

## Tech Used
- Python
- random module for card draws and enemy attacks

## How to run
1. Download or clone this repository.
2. Open the project in a Python editor
3. Run the Python file

## How to play
1. The player starts with 50 HP and the enemy starts with 150 HP. (You can change this)
2. At the beginning of every turn, the player will receive 3 action points (you can use cards to increase your Action Points).
3. Select a card by entering its index number
4. Each card has a specific amount of AP, spend your AP wisely, some cards have unique functions
5. Type 'end' to finish your turn early
6. The enemy will strike at the end of your turn (your turn ends when you type 'end' or you reach 0 AP).
7. Defeat the enemy before your health reaches 0 to win!
